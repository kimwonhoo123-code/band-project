# band-project — Pixel Band Live

유튜브에서 노래를 틀면 화면 오른쪽 아래(작업표시줄 바로 위)에 픽셀 밴드가 나와서 노래에 맞춰 공연하는 크롬 확장프로그램입니다.

> **비공식 팬 프로젝트**입니다. 등장하는 밴드·소속사와는 아무 관련이 없으며, 음원·가사·사진은 포함하지 않습니다.
> 재생 중인 유튜브 소리를 브라우저 안에서 실시간으로 분석만 합니다.

## 기능
- 재생 중인 소리에서 템포(BPM)와 박자 위치를 추정해 멤버들이 박자에 맞춰 움직임
  - 보컬·베이스: 계속 점프, 기타 스트로크
  - 드럼: 스틱으로 탐을 번갈아 치고 4박마다 크래시
- 보컬 입 모양: 목소리 크기와 음절에 맞춰 여러 모음 모양으로 천천히 변화
- 일시정지·광고 중에는 숨김, 전체화면에서도 표시

## 설치
1. 이 저장소를 내려받기 (Code → Download ZIP) 후 압축 풀기
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `pixel-band-live` 폴더 선택 (`manifest.json`이 바로 들어 있는 폴더)
5. 유튜브 탭 새로고침 후 노래 재생

크롬을 **최대화**하면 멤버들이 작업표시줄 바로 위에 서 있는 것처럼 보입니다.

## 단축키
| 키 | 동작 |
|---|---|
| Alt+P | 켜기 / 끄기 |

## 설정 (`pixel-band-live/config.js`)
| 항목 | 설명 |
|---|---|
| `stageMode` | `"taskbar"` 배경 없이 화면 맨 아래 / `"stage"` 무대·조명·관객 박스 |
| `vocalLook` | 보컬 모습 `"live"` / `"stage"` / `"black"` |
| `outfit` | 베이스·드럼 의상 `"stage"` / `"black"` |
| `titleKeywords` | 영상 제목에 이 단어가 있을 때만 등장 (비우면 모든 영상) |
| `mouthHoldMs` | 입 모양이 바뀌는 최소 간격(ms), 클수록 천천히 |
| `scale` | 확대 배율 |

## 파일 구성
```
pixel-band-live/
  manifest.json   확장프로그램 정보 (youtube.com 에서만 실행)
  config.js       설정
  sprites.js      픽셀 캐릭터 그리기
  content.js      영상 찾기, 소리 분석(템포·박자·입 모양), 화면 표시
```

## 한계
- PC 크롬(크로미움 계열)에서만 동작하며 모바일 유튜브 앱은 지원하지 않습니다.
- 그림은 브라우저 창 안에만 그려지므로 다른 창에 가려지면 같이 가려집니다.
- 드럼이 약한 발라드 구간에서는 박자 추정이 부정확할 수 있습니다.
